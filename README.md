## Learning format
### What does ChatGPT do for me?
ChatGPT is acting as my teacher. 
Its role is to supply curriculum for the course.


**What it provides:**


- Lessons on each concept with examples.
- Quizzes to make sure I understood.
- Open discussion after each lesson
- Code review asking questions about the design 
- Spotting bugs and letting me reason them.


**What it DOESN'T do:**

- Write code for me
- Tell me what needs to be changed
- Take away my learning opportunity from my mistakes
| for example if a bug exists in my current code it will point me toward spotting the bug instead of telling me right away.


### What do I do for me? :D

I genuinely want to be able to create my own Minecraft Mod ASAP! So:

- I experiment with what I learn.
- I search forums too not just what ChatGPT provides.
- I write my own code even if it's bad design, or it has bugs.
- I try to understand what breaks and why.
